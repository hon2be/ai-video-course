🎙 나레이션

안녕하세요! 지난 강의에서 파이어플라이로 동일인물을 만드는 방법을 배웠는데요.

오늘은 미드저니에서 같은 인물을 유지하는 방법을 다룹니다.

미드저니는 파이어플라이와 방식이 조금 달라요. Reference Image를 업로드하는 게 아니라 이미지 링크를 프롬프트에 직접 붙여 넣는 방식입니다. 그리고 핵심 파라미터는 두 가지예요 — --cref와 --cw.

01 핵심 개념 — --cref & --cw 파라미터란? 약 2분
🎙 나레이션

두 파라미터를 먼저 이해하고 가겠습니다.

--cref (Character Reference)

캐릭터 레퍼런스. 참고할 인물 이미지의 링크를 지정합니다. 이 파라미터가 있어야 동일인물 기능 자체가 작동합니다.

--cw (Character Weight)

캐릭터 비중. 0~100 사이의 숫자로 레퍼런스를 얼마나 강하게 따를지 조정합니다. 기본값은 100.

💡 --cw 값별 차이
--cw 값얼굴헤어의상언제 쓰나
100 (기본)강하게 참조강하게 참조강하게 참조모든 요소를 최대한 유지할 때
75참조참조일부 변화얼굴·헤어는 유지, 의상은 조금 자유롭게
50참조일부 변화자유롭게얼굴만 유지하고 나머지 변화
25느슨하게 참조자유자유분위기만 비슷하게
0주로 얼굴 윤곽완전 자유완전 자유전혀 다른 스타일로 변환
⚠️ 중요

실제 사람 사진을 --cref에 쓰면 생각보다 반영이 잘 안 됩니다.
미드저니로 생성한 AI 인물 이미지를 레퍼런스로 쓰는 게 훨씬 효과적입니다.

STEP 1 기준 인물 이미지 생성하기 약 2분
🎙 나레이션

먼저 레퍼런스로 쓸 기준 인물을 미드저니에서 생성합니다. 여기서 중요한 게 있어요 — 배경을 흰색(white background)으로 지정하면, 배경에 불필요한 요소가 섞이지 않아서 --cref로 쓸 때 훨씬 깔끔하게 반영됩니다.

📝 기준 인물 생성 프롬프트
// 미드저니 Discord 또는 웹에서 입력 /imagine a Korean woman in her early 20s, long straight black hair with bangs, low ponytail, fair skin, natural makeup, gentle expression, white t-shirt, blue jeans, white background, front-facing, full body, photorealistic, high detail // 핵심 포인트 // - white background: 배경 깔끔하게 // - front-facing: 정면으로 생성해야 나중에 반영이 잘 됨 // - 의상·헤어 묘사를 구체적으로 → cw 100에서 최대한 유지됨
💡 기준 이미지 선택 기준
  • 정면(front-facing)이 가장 좋음 — 측면·후면은 반영률이 낮음
  • 배경이 단색일 것 — 복잡한 배경은 배경까지 함께 참조됨
  • 4장 중 가장 얼굴이 선명하게 나온 것으로 선택
  • 마음에 들면 U버튼(업스케일) 클릭해서 고해상도로 저장
STEP 2 이미지 링크 복사하기 약 1분
🎙 나레이션

파이어플라이는 이미지를 직접 업로드했지만, 미드저니는 이미지 URL 링크를 프롬프트에 넣는 방식이에요. 이 링크를 복사하는 게 핵심입니다.

🖥 Discord에서 링크 복사하는 방법
  • 생성된 이미지를 클릭해서 크게 열기
  • 이미지 위에서 마우스 우클릭
  • 팝업 메뉴에서 "이미지 주소 복사" 클릭
  • 복사된 URL 메모장에 붙여 넣어서 보관
🖥 미드저니 웹(midjourney.com)에서 링크 복사하는 방법
  • 생성된 이미지 클릭 → 상세 화면 열기
  • 이미지 위 우클릭 → "이미지 주소 복사"
  • 또는 이미지를 새 탭에서 열기 → 주소창 URL 복사
⚠️ 주의

Discord에서 생성한 이미지 링크는 만료 기한이 있어요. 오래된 링크는 --cref에 넣어도 작동하지 않습니다. 가능하면 이미지를 내 컴퓨터에 저장해두고, 사용할 때마다 최신 링크를 복사하거나 미드저니 웹에서 업로드 기능을 활용하세요.

STEP 3 --cref로 동일인물 장면 생성하기 약 3분
🎙 나레이션

이제 실전입니다. 링크를 복사했으면 새 프롬프트 뒤에 --cref [링크]를 붙여 넣으면 됩니다.

📝 기본 사용법
// 구조: [원하는 장면 프롬프트] --cref [이미지 링크] a Korean woman sitting at a cozy Seoul cafe, holding a coffee cup, warm smile, soft indoor lighting, wooden interior --cref https://cdn.discordapp.com/attachments/... --cw 100

📌 실전 예시 3컷

📝 컷 1 — 카페 장면
a woman sitting at a cafe, holding a latte, warm smile, wooden interior, bokeh background, medium shot, photorealistic --cref [기준 이미지 링크] --cw 75
📝 컷 2 — 야외 걷기
a woman walking on a busy Seoul street, casual outfit, sunny afternoon, carrying a bag, full body shot, photorealistic --cref [기준 이미지 링크] --cw 50
📝 컷 3 — 의상 변경
a woman wearing an elegant black dress, standing in a modern rooftop restaurant, evening lighting, confident expression, full body, photorealistic --cref [기준 이미지 링크] --cw 0 // --cw 0: 얼굴만 참조, 의상 완전 자유 // 드라마틱하게 의상을 바꿀 때 사용
💡 --cref 사용 포인트
  • 프롬프트 맨 뒤에 --cref 파라미터를 붙임
  • --cw를 명시하지 않으면 기본값 100으로 작동
  • 의상을 바꾸고 싶을 땐 --cw를 낮추고 의상 묘사를 구체적으로
  • 장면·배경은 프롬프트로, 인물은 --cref로 — 역할 분리가 핵심
STEP 4 --cw 값으로 세밀하게 조정하기 약 3분
🎙 나레이션

같은 인물, 같은 링크를 쓰더라도 --cw 값에 따라 결과가 크게 달라집니다. 목적에 따라 어떤 값을 쓸지 정리해 드릴게요.

🖥 화면 안내 — --cw 값별 비교 실연
  • 동일 프롬프트에 --cw 100 / 75 / 50 / 25 / 0 순서로 생성 결과 나란히 비교
  • "cw가 낮아질수록 의상·헤어가 자유로워지고, 얼굴 유사도도 조금씩 낮아집니다"
📝 --cw 비교 프롬프트
a woman wearing futuristic cyberpunk suit, standing in a neon-lit city street, full body, cinematic --cref [기준 이미지 링크] --cw 100 // 위 프롬프트에서 --cw 값만 75 / 50 / 25 / 0으로 바꿔서 비교 // cw 100: 원래 의상 느낌이 남음 // cw 0 : 사이버펑크 수트가 완전히 새롭게 생성됨
💡 목적별 --cw 권장값
  • 광고·상업 이미지 (인물 완전 유지): --cw 100
  • 일반 장면 생성 (얼굴+헤어 유지, 배경 자유): --cw 75
  • 의상 변경 (얼굴만 유지): --cw 25~50
  • 컨셉 아트·판타지 (분위기만 참조): --cw 0
05 실전 활용 팁 약 2분
🎙 나레이션

지금까지 배운 내용으로 실제 영상 제작에 바로 쓸 수 있는 팁들을 정리해 드릴게요.

💡 파이어플라이 vs 미드저니 동일인물 — 어떤 걸 써야 하나?
  • 미드저니 --cref: 이미지 퀄리티 높음, 아트스타일 강함, 링크 방식이라 직관적. 단 링크 만료 주의
  • 파이어플라이 Reference Image: 업로드 방식이라 편리, 한국어 프롬프트 지원, 맞춤형 모델로 발전 가능
  • → 사진 느낌 실사 이미지는 파이어플라이, 일러스트·아트 스타일은 미드저니가 강점
💡 미드저니 --cref 심화 팁
  • 멀티 레퍼런스: --cref [링크1] [링크2] 식으로 여러 이미지 링크를 나열하면 여러 레퍼런스를 혼합해서 참조 가능
  • --sref와 조합: --sref로 스타일 참조 + --cref로 인물 참조를 동시에 쓰면 스타일과 인물을 함께 유지 가능
  • 업스케일 후 재사용: U버튼으로 업스케일한 이미지 링크를 쓰면 더 디테일한 얼굴이 반영됨
  • 기준 이미지 여러 장 준비: 정면·측면·클로즈업 각각 기준 이미지를 만들어두고 상황에 따라 교체

✅ 오늘의 핵심 요약

  • 미드저니 동일인물의 핵심은 --cref (이미지 링크) + --cw (비중 0~100)
  • 기준 인물은 white background, front-facing으로 생성할 것
  • 실제 사진보다 미드저니로 생성한 AI 이미지를 레퍼런스로 쓸 때 효과 더 좋음
  • 의상만 바꾸고 싶으면 --cw 0~25, 전체 유지하려면 --cw 100
  • 링크 만료 주의 — 이미지를 로컬에 저장해두고 새 링크 발급해서 사용
🎙 나레이션

숙제는 미드저니에서 여러분만의 기준 인물을 하나 만들고, --cw 값을 100 / 50 / 0으로 바꿔가며 결과 차이를 비교해 보는 겁니다.
