INTRO 동일인물이 왜 어려운가? 약 1분
🎙 나레이션

안녕하세요! 오늘은 AI 영상 제작에서 가장 많이 받는 질문을 다룰 거예요.

"같은 인물을 여러 장면에 걸쳐 똑같이 유지하려면 어떻게 해요?"

AI의 가장 큰 약점이 바로 일관성입니다. 같은 프롬프트를 써도 생성할 때마다 얼굴이 조금씩 달라지거든요.

오늘은 ChatGPT로 기준 인물을 만들고, 파이어플라이에서 그 인물의 데이터 시트를 구축한 다음, 어떤 장면에서도 똑같은 인물이 나오게 하는 방법을 처음부터 끝까지 보여드릴게요.

🖥 화면 안내
  • 같은 프롬프트로 생성한 이미지 3장 비교 → 얼굴이 다 다름
  • "오늘 배우면 이렇게 됩니다" → 인물1_20대_여성/개별컷/활동/ 이미지 모아서 보여주기 (동일 인물, 다양한 활동)
00 전체 워크플로우 한눈에 보기 약 1분
🎙 나레이션

먼저 오늘 전체 흐름을 보여드릴게요. 크게 다섯 단계입니다.

🖥 화면 안내 — 플로우 다이어그램 또는 슬라이드
  • ① ChatGPT로 기준 인물 프롬프트 작성 & 이미지 생성
  • ② Firefly에서 Reference Image로 인물 데이터 시트 생성 (헤드샷 / 전신 멀티샷 / 표정 시트 / 활동 시트)
  • ③ 그리드 이미지를 개별 컷으로 잘라 폴더별 정리

  • ⑤ Structure Reference로 포즈까지 제어
💡 강의 포인트

"GPT에서 뽑은 이미지를 파이어플라이의 레퍼런스로 쓰는 것 — 두 툴의 장점을 결합하는 워크플로우입니다."

STEP 1 ChatGPT로 기준 인물 만들기 약 3분
🎙 나레이션

첫 번째 단계는 우리 영상에 등장할 인물의 기준 이미지를 ChatGPT에서 만드는 겁니다.

왜 GPT냐고요? GPT의 DALL-E는 인물 묘사에 강하고, 한 번 잘 나온 이미지를 파이어플라이 레퍼런스로 그대로 가져다 쓸 수 있거든요.

중요한 건 이 기준 이미지 하나가 앞으로 모든 장면의 '원본'이 된다는 거예요. 그래서 정면, 단색 배경, 전신 또는 상반신이 명확하게 나오도록 만들어야 합니다.

🖥 화면 안내
  • ChatGPT 화면 열기 → 이미지 생성 프롬프트 입력 실연
  • 생성 결과에서 인물1_20대_여성/front.png 보여주기 (이미 만든 예시로 사용)
  • "이 분이 오늘 예시 인물입니다" 소개
📝 GPT 기준 인물 프롬프트 예시
// ChatGPT DALL-E에 입력 A full-body portrait of a Korean woman in her early 20s, long straight black hair in a low ponytail with bangs, fair skin, natural makeup, gentle expression, wearing a white t-shirt and straight-leg blue jeans, plain light gray studio background, front-facing, standing, natural studio lighting, photorealistic, high detail
💡 기준 이미지 체크리스트
  • 정면 바라보기 (front-facing)
  • 단색 배경 (plain gray / white background)
  • 전신 또는 상반신이 프레임 안에 들어올 것
  • 헤어·눈·피부 톤 등 외모 묘사를 최대한 구체적으로
  • 마음에 드는 이미지가 나오면 반드시 저장 — 이게 원본 파일
STEP 2 파이어플라이에서 인물 데이터 시트 뽑기 약 4분
🎙 나레이션

기준 이미지가 있으면 이제 파이어플라이에서 인물의 다양한 모습을 '데이터 시트' 형태로 생성합니다.

데이터 시트란 같은 인물을 여러 각도, 여러 표정, 여러 활동으로 그리드 형태로 뽑은 이미지예요. 이걸 만들어 두면 나중에 레퍼런스 이미지로 쓰기가 훨씬 편해집니다.

총 네 종류의 시트를 만들 거예요 — 헤드샷 시트, 전신 멀티샷, 표정 시트, 활동 시트.

🖥 화면 안내 — Reference Image 설정
  • 파이어플라이 Text to Image 열기
  • 오른쪽 Style 패널 → Reference Image에 front.png 업로드
  • Strength 슬라이더 60% 설정

⚠️ 이미지 해상도 기준

데이터 시트로 생성되는 개별 이미지 1장당 가로 최소 1024px 이상이어야 합니다.
그리드 시트를 나눴을 때 각 컷이 1024px 미만이면 Reference Image로 쓸 때 품질이 떨어져 인물 일관성이 낮아집니다.
파이어플라이 생성 해상도를 4:3 이상 (최소 2048×1536)으로 설정하거나, 그리드 열 수를 줄여서 컷당 해상도를 확보하세요.

해상도가 부족한 이미지는 Upscayl(무료 오픈소스)로 업스케일 후 사용하세요. AI 기반으로 화질 손상 없이 2~4배 확대할 수 있습니다.

💡 강의 포인트
  • Reference Image Strength는 55~65%가 가장 잘 맞는 구간. 너무 높으면 그리드 포맷이 안 잡히고, 너무 낮으면 인물 얼굴이 달라집니다.
  • 한 번에 완벽하게 나오지 않아도 괜찮아요. 가장 비슷한 결과물을 골라서 저장하면 됩니다.
STEP 3 데이터 시트를 개별 컷으로 정리하기 약 2분
🎙 나레이션

그리드로 된 시트를 한 장 한 장 잘라서 저장해 두세요. 나중에 Reference Image로 업로드할 때 딱 필요한 컷만 골라 쓸 수 있거든요.

폴더 구조는 이렇게 만들면 찾기 편합니다.

STEP 4 장면별 이미지 선택 가이드 약 4분
🎙 나레이션

이제 실전입니다. 핵심은 하나예요 — 만들 장면의 분위기와 가장 비슷한 개별컷을 Reference Image로 고른다.

파이어플라이는 레퍼런스 이미지의 조명·배경·표정·포즈까지 참고합니다. 단순히 "같은 얼굴"을 원하는 게 아니라, 레퍼런스 이미지의 전체 분위기가 결과에 영향을 줘요.

지금부터 장면 유형별로 어떤 이미지를 언제 쓰는지 보여드릴게요.
