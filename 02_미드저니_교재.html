단원 1

미드저니(Midjourney) 소개와 인터페이스

📌 학습 목표
  • 미드저니가 무엇이고 어떤 작업을 할 수 있는지 설명할 수 있다.
  • 공식 사이트의 화면 구성과 주요 메뉴를 파악한다.
  • 생성 옵션 패널의 4가지 영역을 이해하고 조작할 수 있다.
  • Creation Actions의 핵심 기능(Vary, Upscale, Animate)을 사용할 수 있다.
  • 자주 쓰는 파라미터를 프롬프트에 적용할 수 있다.

1.1  미드저니란?

미드저니(Midjourney)는 텍스트 프롬프트를 입력하면 AI가 이미지를 생성해 주는 도구다. 사진·일러스트·콘셉트 아트·영상용 스틸까지 폭넓게 다룰 수 있어, 단편 영상의 '컷별 이미지'를 만드는 작업에 적합하다.

  • 입력 — 한 줄의 문장(프롬프트) + 파라미터
  • 출력 — 정사각형 / 세로 / 가로 비율의 이미지 (또는 짧은 영상)
  • 강점 — 사진 같은 사실적 톤부터 동화풍까지 '스타일' 제어가 매우 풍부
  • 작업 흐름 — 프롬프트 작성 → 결과 확인 → 마음에 드는 이미지 선택 → Variation/Upscale 반복

1.2  공식 사이트의 화면 구성

미드저니는 웹 기반으로 작동한다. midjourney.com에서 로그인 후 좌측 메뉴와 상단 프롬프트 입력창이 작업의 중심이다.

좌측 메뉴 한눈에 보기

메뉴설명
Explore다른 사용자의 작품을 둘러보며 영감·스타일 찾기
Create프롬프트를 입력해 이미지를 생성하는 메인 작업 공간
Edit이미 생성한 이미지를 수정 (확장·재생성·Retexture 등)
Organize내가 만든 이미지 정리 (폴더·태그 관리)
Personalize내 취향을 학습시키는 개인 스타일 프로파일
Moodboards분위기 보드 — 여러 이미지를 묶어 스타일 기준 생성
Style Creator내 스타일 ID(--sref) 만들기
Tasks내가 생성한 작업 히스토리·대기열

Moodboards — 분위기 보드

Moodboards는 원하는 스타일의 이미지들을 모아 '분위기 기준'을 만드는 도구다. 무드보드를 만들면 미드저니가 그 분위기를 참고해 이미지를 생성한다.

Organize — 작업 이력 관리

Organize에서는 내가 생성한 모든 이미지와 영상을 한 곳에서 보고 필터링할 수 있다. Media Type, Aspect Ratio, Version 등으로 검색이 가능하다.

1.3  생성 옵션 패널

상단 프롬프트 창 옆의 설정 아이콘을 누르면 옵션 패널이 열린다. 이 4개 박스를 이해하면 90%의 작업이 끝난다.

(1) Aspect Ratio — 화면 비율

  • Portrait — 세로형. 모바일·쇼츠·릴스에 최적 (9:16, 3:4)
  • Square — 정사각형. 썸네일·SNS 포스트
  • Landscape — 가로형. 유튜브·시네마틱 (16:9, 21:9)
💡 TIP
  • 영상 컷용이라면 16:9 또는 9:16으로 먼저 통일하자.

(2) Aesthetics — 미학

  • Stylization — 미적 스타일 적용 강도. 낮으면 사실적, 높으면 회화적·드라마틱
  • Weirdness — 결과의 '기괴함'. 낮으면 안정적, 높으면 실험적
  • Variety — 결과 다양성. 낮으면 비슷한 컷, 높으면 다양한 시도

(3) Model — 버전 선택

  • Version — 사용할 미드저니 버전 (예: 7, 6.1). 기본은 Standard.
  • Draft / Standard — Draft는 빠르고 저렴, Standard는 고품질
  • Raw — 자동 보정 끔. 사실적 결과·사진풍 작업에 유리

(4) More Options — 속도와 영상

  • Speed — Relax(느리지만 무제한) / Fast(기본) / Turbo(가장 빠름)
  • Video Resolution — 영상 출력 해상도 (SD / HD)
  • Video Batch Size — 한 번에 생성할 영상 개수

영상을 생성할 때는 Start Frame과 End Frame을 설정하거나, 이미 생성한 이미지에서 Animate Image를 선택해 애니메이션으로 변환할 수 있다.

1.4  생성한 이미지로 할 수 있는 일

이미지가 생성되면 우측에 Creation Actions 패널이 나타난다. 영상 제작에서 가장 자주 쓰는 기능들을 정리한다.

기능설명
Vary — Subtle / Strong같은 이미지를 조금/많이 변형해 새 버전 생성
Upscale — Subtle / Creative이미지 해상도를 업스케일 (화질 향상)
More — Rerun / Edit같은 프롬프트로 다시 생성하거나 Edit 모드로 진입
Use — Image이 이미지를 참조 이미지(--cref/iref)로 사용. 캐릭터 일관성 유지에 활용
Use — Style이 이미지의 '스타일'만 차용(--sref). 화풍 통일에 사용
Use — Prompt이 이미지를 만든 프롬프트를 그대로 가져와 새 입력창에 채움
Animate Image스틸 이미지에 움직임을 부여해 짧은 영상으로 변환

1.5  자주 쓰는 파라미터 정리

파라미터설명
--ar 9:16화면 비율 지정 (가로 16:9 / 세로 9:16 / 정사각 1:1)
--cref [URL]캐릭터 참조. 동일 인물 유지에 사용
--sref [ID/URL]스타일 참조. 같은 화풍으로 통일
--p [ID]개인 스타일 프로파일 적용, 무드보드
--chaos 0~100결과 다양성. 높을수록 변화 큼
--stylize 0~1000미적 강조 강도
--no [keyword]특정 요소 제외 (예: --no glasses)

1.6  Edit 기능 — 이미지 수정

Edit 메뉴에서는 생성한 이미지를 직접 수정할 수 있다. 대표적인 기능인 Retexture와 Erase를 활용하면 이미지의 일부를 바꾸거나 새로운 요소를 추가할 수 있다.

주요 Edit 도구

  • Retexture — 선택한 영역의 질감·스타일을 프롬프트로 변경
  • Erase (지우기) — 브러시로 칠한 영역을 지워 새로운 요소 생성 가능
  • Restore — 지운 영역을 원래대로 복원
  • Smart Select — 자동으로 오브젝트를 선택
  • Move / Resize — 오브젝트를 이동하거나 크기 조정

Erase 후 상단 프롬프트 창에 원하는 요소를 입력하고 Submit Edit을 누르면 AI가 해당 영역에 새로운 내용을 그려 넣는다.

✅ 단원 1 마무리 체크리스트
  • Explore에서 마음에 드는 스타일을 3개 찾아 Reference Style로 저장했다.
  • 내 영상 비율(9:16 또는 16:9)을 결정하고 Aspect Ratio를 설정해 봤다.
  • 이미지를 생성하고 Vary, Upscale, Animate Image를 각각 한 번씩 사용해 봤다.
  • --cref와 --sref 파라미터를 직접 프롬프트에 적어 봤다.
단원 2

캐릭터·화풍·프롬프트 설계

📌 학습 목표
  • AI 영상 생성에서 인물 일관성을 유지하는 방법을 이해한다.
  • 화풍(스타일)과 캐릭터 설정을 프롬프트에 체계적으로 반영할 수 있다.
  • 컷 단위 프롬프트 구성 공식을 실전에 적용할 수 있다.

2.1  화풍(Style) 정하기

Midjourney에서 '화풍'은 영상의 전반적 룩을 결정한다. 원하는 화풍이 있다면 Explore에서 마음에 드는 이미지를 찾아 그 스타일 ID(--sref 또는 --p)를 모든 컷에 일관되게 적용하는 것이 핵심이다.

2.2  캐릭터 일관성 (--cref)

같은 인물이 여러 컷에 등장할 때는 '기준 인물 이미지'를 먼저 만들고, 이후 모든 컷에서 그 이미지를 --cref로 참조시킨다. 그래야 머리 모양·얼굴·체형이 흔들리지 않는다.

  1. 기준 이미지 1장을 먼저 확정한다.
  2. 이후 모든 프롬프트 끝에 --cref [URL]을 붙인다.
  3. 필요하면 두 장 이상 참조해 강도를 높일 수 있다.

2.4  의상 묘사 템플릿 — 한국 교복

의상은 매 컷마다 다시 묘사해야 일관성이 유지된다. 아래 문장을 그대로 복사해 사용해도 좋다.

의상 프롬프트 템플릿
realistic Korean school uniform, full-length navy school blazer with white collar,
pleated dark navy skirt, white dress shirt, school bag,
white socks and loafers

2.5  컷 단위 프롬프트 구성 공식

📐 프롬프트 6-레이어 공식
  • 샷 사이즈 + 앵글   예: medium close-up, low angle
  • 피사체 + 행동   예: a Korean girl checking her phone
  • 배경·시간대   예: morning street, soft sunlight
  • 의상·외형 묘사   (캐릭터 시트 참조)
  • 화풍·렌더링   예: cinematic realism, documentary style
  • 파라미터   --ar 9:16 --p [ID] --cref [URL]
✅ 단원 2 마무리 체크리스트
  • 화풍 기준이 되는 스타일 ID(--sref/--p)를 확정했다.
  • 등장 인물별 기준 이미지를 1장씩 생성하고 URL을 저장했다.
  • 캐릭터 시트를 완성하고 의상 묘사 문장을 정리했다.
  • 6-레이어 공식을 사용해 컷 1장을 완성했다.
